# BroGlow

Монитор локальных сессий Claude Code, opencode, Codex и GitHub Copilot CLI
с приложением в строке меню, терминальной панелью и необязательной лампой ESP32-C3.
Лампа показывает работу, ожидание и запрос ввода через USB или Bluetooth LE.
Версия **1.0.0** готовится к выпуску.

Проект поддерживает **Suren Khorenyan**. Уведомления об авторских правах — в [LICENSE](LICENSE).

<a name="why-this-version"></a>

## Зачем эта версия?

BroGlow — отдельное, независимо поддерживаемое приложение на основе
[ClawLight](https://github.com/clawlight/clawlight-cli). В нём существенно
переработаны и расширены возможности оригинала: добавлены управление лампой
по Bluetooth на macOS, улучшенная интеграция с настольным Codex, настройка
отдельных ламп и их яркости, настраиваемый печатный корпус и двуязычное
интерактивное руководство по сборке.

| Что улучшилось | Что это даёт вам |
| --- | --- |
| **Беспроводное подключение** | Поставьте лампу в зоне действия Bluetooth без кабеля передачи данных к Mac. |
| **Поддержка Codex (приложение ChatGPT)** | Переходите прямо к нужному разговору; названия задач обновляются после переименования. |
| **Очистка приостановленных сессий** | Уберите лишнее одним нажатием: работающие сессии и запросы разрешений останутся видимыми. |
| **Предпросмотр яркости** | Выберите комфортную яркость для каждой лампы и оцените результат до сохранения. |
| **Настройка из приложения** | Подключите нужную лампу с помощью пошаговой настройки через USB. |
| **Понятный статус подключения** | Узнайте, получает ли каждая лампа обновления или требует внимания. |
| **Сохранённые лампы с именами** | Сохраняйте настройки домашней и офисной ламп и легко различайте их. |
| **Печать и настройка корпуса** | Выберите внешний вид и измените конструкцию под свои предпочтения. |
| **Поиск нужной лампы** | Включите мигание выбранной лампы, чтобы убедиться, какой вы управляете. |
| **Интерактивное руководство по сборке** | Вращайте и приближайте разнесённые детали, чтобы понять, как они соединяются. |

Беспроводное управление и прямое открытие задач Codex доступны на macOS.
Лампе по-прежнему нужно питание; устройство рассчитано на самостоятельную сборку.

<a name="install"></a>

## Установка

Скачайте полный пакет для архитектуры вашего Mac и соответствующий файл
`.sha256` в разделе **Releases этого репозитория**. Следуйте [инструкции по
проверке контрольной суммы и установке](site/guide/ru/hardware.md#install-a-prebuilt-package).
Сборки не нотарифицированы с Developer ID; руководство описывает обычную
процедуру разрешения запуска отдельного приложения в macOS.

На Windows распакуйте архив Windows из Releases в постоянную папку.
Откройте PowerShell в этой папке и выполните `.\broglow.exe install`, чтобы
зарегистрировать хуки, включить автозапуск при входе и запустить приложение в трее.
`.\broglow.exe menubar` запускает графический интерфейс в трее напрямую;
`.\broglow.exe` открывает терминальную панель.

Чтобы вместо этого собрать приложение из исходников:

```bash
cargo install --locked --path .
"$HOME/.cargo/bin/broglow" install
```

На Linux перед компиляцией установите [системные библиотеки разработки](CONTRIBUTING.ru.md#development-setup).
На Windows используйте Rust MSVC, добавьте собранный
исполняемый файл в PATH, затем выполните `broglow install`.
Установка приложения не прошивает плату.

На macOS нажмите **⌘ Space**, найдите **BroGlow** и нажмите Return, чтобы открыть
управление. Приложение находится в `~/Applications/BroGlow.app` и запускается
при входе. Также можно выполнить `open "$HOME/Applications/BroGlow.app"`.
Команда `broglow` в Terminal открывает необязательную терминальную панель.

<a name="connect-your-coding-agents"></a>

## Подключение coding-агентов

Установщик регистрирует хуки только для обнаруженных агентов; уже запущенные
сессии может потребоваться перезапустить.

| Агент | Особенности настройки |
| --- | --- |
| Claude Code | Хуки в `~/.claude/settings.json`. |
| opencode | Установленный плагин; перезапустите работающие сессии. |
| Codex | Codex >= 0.144; проверьте хуки через `/hooks`. [Настройка локальной задачи в приложении](site/guide/ru/hardware.md#connect-local-codex-sessions). |
| GitHub Copilot CLI | Установленные хуки; перезапустите сессии, открытые во время установки. |

Облачные задачи и обычные разговоры в ChatGPT не отправляют локальные хуки этого Mac.

<a name="use-it"></a>

## Использование

Значок в строке меню открывает сессии и **Lamps**: добавьте лампу через USB,
задайте имя или яркость. Сохранённые лампы работают независимо.
Кнопка **×** скрывает сессию до новой активности; разговор остаётся в приложении агента.

```text
broglow --version          Узнать установленный релиз
broglow                    Открыть терминальную панель
broglow ble pair           Определить и запомнить прошитую C3 через USB
broglow ble status         Проверить текущую доставку статуса лампе
broglow dashboard-button show   Включить необязательные кнопки панели
broglow uninstall          Удалить хуки, автозапуск и настройки BroGlow
```

Приложение запускается при входе в систему. Запрос ввода имеет приоритет цвета;
Settings выбирает жёлтый или зелёный при сочетании работы и ожидания.
Прошивка, сопряжение и диагностика описаны в [руководстве](site/guide/ru/hardware.md).
