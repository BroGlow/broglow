# ClawLight

Монитор локальных сессий Claude Code, opencode, Codex и GitHub Copilot CLI
с приложением в строке меню, терминальной панелью и необязательной лампой ESP32-C3.
Лампа показывает работу, ожидание и запрос ввода через USB или Bluetooth LE.
Версия **1.0.0** готовится к выпуску.

## Начните здесь

- **Установка или обновление:** [руководство по настройке](docs/hardware-setup.ru.md#install-or-update-the-mac-service).
- **Подключение прошитой лампы:** [настройка через USB](docs/hardware-setup.ru.md#usb-assisted-setup).
- **Сборка и подключение C3:** [руководство по устройству](docs/hardware-setup.ru.md#wiring-and-resistor-choice).
- **Печать необязательного корпуса:** [печать и сборка](models/clawlight/PRINT_GUIDE.md).
- **Публикация релиза или сайта:** [инструкция для сопровождающих](docs/releasing.ru.md) в репозитории исходников.

Пакеты Mac содержат приложение, прошивку C3 и руководства; архивы Windows —
**CLI-only**, а на Linux приложение собирают из исходников. BLE доступен только
на macOS. Apple Silicon проверена локально; для остальных машин см.
[ограничения проверок](docs/hardware-setup.ru.md#repeatable-checks-and-results).
Релиз-кандидат корпуса для 1.0.0 скачивается отдельно.

<a name="install"></a>

## Установка

Скачайте полный пакет для архитектуры вашего Mac и соответствующий файл
`.sha256` в разделе **Releases этого репозитория**. Следуйте [инструкции по
проверке контрольной суммы и установке](docs/hardware-setup.ru.md#install-a-prebuilt-package).
Сборки не нотарифицированы с Developer ID; руководство описывает обычную
процедуру разрешения запуска отдельного приложения в macOS.

Чтобы вместо этого собрать приложение из исходников:

```bash
cargo install --locked --path .
"$HOME/.cargo/bin/clawlight" install
```

На Linux перед компиляцией установите системные библиотеки разработки из
`.github/workflows/ci.yaml`. На Windows используйте Rust MSVC, добавьте собранный
исполняемый файл в PATH, затем выполните `clawlight install`.
Установка приложения не прошивает плату.

<a name="connect-your-coding-agents"></a>

## Подключение coding-агентов

Установщик регистрирует хуки только для обнаруженных агентов; уже запущенные
сессии может потребоваться перезапустить.

| Агент | Особенности настройки |
| --- | --- |
| Claude Code | Хуки в `~/.claude/settings.json`. |
| opencode | Установленный плагин; перезапустите работающие сессии. |
| Codex | Codex >= 0.144; проверьте хуки через `/hooks`. [Настройка локальной задачи в приложении](docs/hardware-setup.ru.md#connect-local-codex-sessions). |
| GitHub Copilot CLI | Установленные хуки; перезапустите сессии, открытые во время установки. |

Облачные задачи и обычные разговоры в ChatGPT не отправляют локальные хуки этого Mac.

<a name="use-it"></a>

## Использование

Значок в строке меню открывает сессии и **Lamps**: добавьте лампу через USB,
задайте имя или яркость. Сохранённые лампы работают независимо.
Кнопка **×** скрывает сессию до новой активности; разговор остаётся в приложении агента.

```text
clawlight --version          Узнать установленный релиз
clawlight                    Открыть терминальную панель
clawlight ble pair           Определить и запомнить прошитую C3 через USB
clawlight ble status         Проверить текущую доставку статуса лампе
clawlight dashboard-button show   Включить необязательные кнопки панели
clawlight uninstall          Удалить хуки, автозапуск и настройки ClawLight
```

Приложение запускается при входе в систему. Запрос ввода имеет приоритет цвета;
Settings выбирает жёлтый или зелёный при сочетании работы и ожидания.
Прошивка, сопряжение и диагностика описаны в [руководстве](docs/hardware-setup.ru.md).
