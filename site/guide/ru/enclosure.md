# Релиз-кандидат корпуса

Продолжайте работу с [текущими CAD и руководством по печати](../../../models/broglow/PRINT_GUIDE.md).
Владелец принял текущий корпус как релиз-кандидат для 1.0.0.
Сохраняйте его геометрию, параметры и результаты проверок; меняйте конструкцию
только по запросу. Финальные физические испытания продолжаются на этом кандидате.

Используйте наши измерения компонентов, исходники CAD, фотографии и рендеры.

Для электроники и проводки следуйте [руководству по устройству](hardware.md).
Для изображений к публикации — [списку необходимых фотографий](media.md).
Записывайте результаты физической примерки по готовой печатной сборке.
