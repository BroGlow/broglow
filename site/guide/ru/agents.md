# Подключите coding-агентов

`broglow install` регистрирует хуки для Claude Code и для каждого другого
поддерживаемого агента, который найдёт на этом компьютере. Только Codex просит вас их
подтвердить. Доказательство, что агент подключён, — смена статуса в списке сессий
BroGlow, а не горящая лампа.

| Агент | Что делает `broglow install` | Что делаете вы |
| --- | --- | --- |
| Claude Code | Добавляет хуки в `~/.claude/settings.json`. | Ничего; новые сессии видны сразу. |
| Codex | Добавляет хуки в `$CODEX_HOME/hooks.json`. | [Разрешите их в `/hooks`](#codex-setup). |
| opencode | Устанавливает плагин `~/.config/opencode/plugins/broglow.js`. | Перезапустите работающие сессии. |
| GitHub Copilot CLI | Записывает `~/.copilot/hooks/broglow.json`. | Перезапустите сессии, открытые во время установки. |

Отслеживаются только задачи, выполняемые на этом компьютере: облачные и удалённые
задачи и обычные чаты ChatGPT до локальной службы BroGlow не доходят. Соответствие
событий статусам для каждого агента описано в
[техническом руководстве](hardware.md#connect-local-codex-sessions). Возврат к сессии,
названия и скрытие одинаковы для всех агентов: [Работа с сессиями](sessions.md).

<a name="claude-code"></a>

## Claude Code

Настраивать нечего. Сессии в терминале и в приложении Claude сообщают статус начиная со
следующего запроса.

<a name="codex-setup"></a>

## Codex

Установка BroGlow добавляет хуки в `$CODEX_HOME/hooks.json` (по умолчанию
`~/.codex/hooks.json`), но для их запуска Codex нужно ваше разрешение.

1. Откройте Codex CLI (0.144 или новее) в терминале. Для задач в приложении используйте
   того же пользователя и тот же `CODEX_HOME`, что и приложение: подойдёт встроенный CLI
   приложения (например, `/Applications/ChatGPT.app/Contents/Resources/codex`) или
   установленная команда `codex` с тем же `CODEX_HOME`.
2. Введите `/hooks`. Проверьте и разрешите восемь записей BroGlow: `SessionStart`,
   `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `PermissionRequest`, `Stop`,
   `Interrupt` и `SessionEnd` (для последних двух нужна свежая версия Codex).
   Каждая подписана **BroGlow: update session status** и запускает `broglow`
   по полному пути с аргументом `codex-hook`, например
   `"/path/to/broglow" codex-hook`. Остальные хуки оставьте без изменений. После
   изменения хуков разрешение может потребоваться снова.
3. Отправьте запрос в новой локальной задаче Codex — в CLI или приложении.
   В списке сессий BroGlow проверьте, что эта задача показывает **Working** во время
   работы и **Paused** после ответа. Запрос ручного подтверждения или блокирующий вопрос
   показывает **Needs help**. Автоматическая проверка разрешения сохраняет **Working**,
   если проверяющий текущего хода указан в журнале; без этих метаданных запросы
   разрешения по-прежнему показывают **Needs help**. Прерывание хода ставит его на паузу;
   завершённая сессия перестаёт влиять на текущий статус. На цвет лампы также влияют
   другие живые сессии и выбор в **Settings → Mixed sessions**.

<a name="codex-missing-hooks"></a>

### Если записей BroGlow нет

BroGlow добавляет хуки Codex, только если Codex уже был установлен при настройке BroGlow.
Если вы установили Codex позже, снова выполните `broglow install` и откройте `/hooks`.

Если Codex сообщает, что хуки отключены, сами включите `hooks = true` в разделе
`[features]` файла `config.toml` Codex. BroGlow этот файл никогда не меняет.

<a name="codex-no-session"></a>

### Если сессия не появилась

Старым задачам в боковой панели нужен новый запрос. Если сессия не появилась, завершите
активную работу, перезапустите Codex и попробуйте снова. Подключённая лампа не
доказывает, что хуки работают: это подтверждает только смена статуса в списке сессий
BroGlow.

Обычные чаты ChatGPT и облачные или удалённые задачи не передают события локальной
службе BroGlow.

<a name="opencode"></a>

## opencode

opencode загружает плагины при запуске, поэтому сессии, работавшие во время установки
BroGlow, появятся только после перезапуска. Если вы установили opencode позже, снова
выполните `broglow install`, чтобы добавить плагин.

<a name="copilot"></a>

## GitHub Copilot CLI

Copilot читает хуки при старте сессии, поэтому перезапустите сессии, открытые во время
установки. Если вы установили Copilot позже, снова выполните `broglow install`.
