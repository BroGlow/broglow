# Соберите лампу

Лампа из трёх светодиодов (ESP32-C3 SuperMini с красным, жёлтым и зелёным) в
напечатанном корпусе, которая показывает состояние сессий вашего агента. Маскот
держится на магнитах — его можно сменить в любой момент.

Ждёте детали или уже собрали лампу? [Установите BroGlow](installation.md):
приложение и терминальная панель показывают локальные сессии агентов и их статусы
даже без лампы.

<a name="parts"></a>

## Выберите детали

Файлы корпуса: [Printables](https://www.printables.com/model/1884645),
[MakerWorld](https://makerworld.com/models/3468773) или
[GitHub Releases]({{ repo_url }}/releases) (контрольная сумма — в разделе [Печать и сборка](printing.md)).

| Деталь | Кол-во | Нужна | Что выбрать |
| --- | --- | --- | --- |
| Плата | 1 | ✅ | ESP32-C3 SuperMini; прошивка рассчитана только на ESP32-C3. Перед прошивкой [определите плату](hardware.md#build-and-identify-the-board). |
| Светодиоды | 3 | ✅ | 5 мм (под отверстия корпуса), по одному красному, жёлтому и зелёному. |
| Резисторы | 3 | ✅ | 330 Ом для красного и жёлтого, 220 Ом для зелёного; 1/8 или 1/4 Вт. |
| Провода | — | ✅ | Для светодиодов и общего GND. |
| USB-кабель | 1 | ✅ | USB-C с передачей данных (не только для зарядки) — для настройки и питания. |
| USB-блок | 1 | ➖ | Только macOS: питает лампу вдали от Mac, тогда Mac связывается с ней по Bluetooth. |
| Напечатанный корпус | 1 комплект | ✅ | Файлы корпуса — выше: маскот, два глаза, светофор и задняя крышка. PETG оранжевого и чёрного цвета. |
| Держатель светодиодов | 1 | ⭐ | Печатается вместе с корпусом. Без него светодиоды держатся только трением и могут провалиться внутрь. |
| Саморезы крышки | 3 | ✅ | DIN 7982 ST2,2 × 6,5 мм с потайной головкой. |
| Саморез держателя | 1 | ⭐ | Такой же саморез; нужен только вместе с держателем светодиодов. |
| Магниты | 4 | ✅ | Ø3×2 мм N52 с осевой намагниченностью: два в маскоте, два в светофоре. |
| Клей | — | ✅ | Для глаз и магнитов. |

✅ обязательно · ⭐ рекомендуем · ➖ по желанию

<a name="wiring"></a>

## Подключите светодиоды

Отключите USB-питание. На ESP32-C3 SuperMini используйте контакты 0, 1 и 3 со стороны
GND (GPIO2 пропустите: он участвует в выборе режима загрузки). К контакту 5 В
светодиоды не подключайте.
