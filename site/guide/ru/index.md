# Соберите лампу

Лампа из трёх светодиодов (ESP32-C3 SuperMini с красным, жёлтым и зелёным), которая
показывает состояние сессий вашего агента. Корпус для 3D-печати необязателен.

Уже собрали лампу? [Установите BroGlow и подключите лампу](installation.md).

<a name="parts"></a>

## Выберите детали

<!-- model-download -->

| Деталь | Что выбрать |
| --- | --- |
| Плата · 1 | ESP32-C3 SuperMini; прошивка рассчитана только на ESP32-C3. Перед прошивкой [определите плату](hardware.md#build-and-identify-the-board). |
| Светодиоды · 3 | 5 мм, по одному красному, жёлтому и зелёному (отверстия корпуса рассчитаны на 5 мм). |
| Резисторы · 3 | 330 Ом для красного и жёлтого, 220 Ом для зелёного; 1/8 или 1/4 Вт. |
| Провода | Для светодиодов и общего GND. |
| USB-кабель · 1 | USB-C с передачей данных (не только для зарядки) — для настройки и питания. |
| USB-блок · необязательно | Только macOS: питает лампу вдали от Mac, тогда Mac связывается с ней по Bluetooth. |
| Корпус · необязательно | Комплект для печати — выше: магнитный (рекомендуем) или клеевой. PETG оранжевого и чёрного цвета. Лампа работает и без корпуса. |
| Саморезы · 4 · только для корпуса | DIN 7982 ST2,2 × 6,5 мм с потайной головкой: три для задней крышки, один для держателя светодиодов. |
| Магниты · 4 · только для магнитного корпуса | Ø3×2 мм N52 с осевой намагниченностью для съёмного маскота. |
| Клей · только для корпуса | Для глаз, а в магнитном корпусе ещё и для магнитов. |

<a name="wiring"></a>

## Подключите светодиоды

Отключите USB-питание. На ESP32-C3 SuperMini используйте контакты 0, 1 и 3 со стороны
GND (GPIO2 пропустите: он участвует в выборе режима загрузки). Каждый из этих GPIO
подключите через свой резистор к аноду (+) светодиода. Все катоды (−) соедините
с GND; к контакту 5 В светодиоды не подключайте.

С этими номиналами светодиоды эталонной сборки светятся одинаково ярко. Для других
светодиодов смотрите [рекомендации по резисторам](hardware.md#wiring-and-resistor-choice).
