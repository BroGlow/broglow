# Соберите лампу { #build }

Уже собрали лампу? [Установите ClawLight и подключитесь](installation.md).

## Выберите детали { #parts }

[Скачать модели · ZIP ↓](../../../models/clawlight-print-pack.zip){ download }

| Деталь | Что выбрать |
| --- | --- |
| Плата · 1 | Формфактор SuperMini с Bluetooth LE. Рекомендуем ESP32-C3 SuperMini. |
| Светодиоды · 3 | По одному красному, жёлтому и зелёному. Готовая модель корпуса рассчитана на светодиоды 5 мм. |
| Резисторы · 3 | По одному на каждый светодиод; номиналы указаны на схеме ниже. |
| Провода | Для светодиодов и общего GND. |
| USB-кабель · 1 | С передачей данных и разъёмом вашей платы. Для первой настройки и питания от Mac. |
| USB-блок · необязательно | Если хотите поставить лампу отдельно. Можно оставить питание от USB-порта Mac. |
| Корпус · необязательно | Модели в `clawlight-print-pack.zip`. Начните с деталей для проверки посадки. |
| Крепёж корпуса | Для готового корпуса: 5 потайных саморезов DIN 7982 ST2.2 × 6,5 мм, 2 стяжки шириной 2,5 мм и толщиной не более 1 мм, клей для пластика. |

Выбрали другую SuperMini с Bluetooth LE? Адаптируйте прошивку и назначение выводов под её чип и
проверьте посадку в корпус. Комплектная прошивка рассчитана на ESP32-C3.

## Подключите светодиоды { #wiring }

Отключите USB-питание. Каждый вывод подключите через свой резистор к аноду (+)
светодиода. Все катоды (−) соедините с GND; к 5V светодиоды не подключайте.

Схема для рекомендуемой ESP32-C3: используйте выводы со стороны GND, пропустив
GPIO2 — он участвует в выборе режима загрузки. Для другой платы проверьте назначение выводов.

На схеме: red — красный, yellow — жёлтый, green — зелёный.
