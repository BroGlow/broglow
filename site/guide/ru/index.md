# Соберите лампу

BroGlow — это приложение, прошивка ESP32-C3 и корпус для 3D-печати.

Уже собрали лампу? [Установите BroGlow и подключитесь](installation.md).

<a name="parts"></a>

## Выберите детали

<!-- model-download -->

| Деталь | Что выбрать |
| --- | --- |
| Плата · 1 | ESP32-C3 SuperMini; прошивка проекта рассчитана на эту плату. |
| Светодиоды · 3 | По одному красному, жёлтому и зелёному. В корпусе используются светодиоды 5 мм. |
| Резисторы · 3 | По одному на каждый светодиод; номиналы указаны на схеме ниже. |
| Провода | Для светодиодов и общего GND. |
| USB-кабель · 1 | С передачей данных и разъёмом вашей платы. Для первой настройки и питания от Mac. |
| USB-блок · необязательно | Если хотите поставить лампу отдельно. Можно оставить питание от USB-порта Mac. |
| Корпус · необязательно | Релиз-кандидат 1.0.0; комплект для печати — выше. Лампа работает и без корпуса. |

Перед прошивкой проверьте чип: комплектная прошивка рассчитана только на ESP32-C3.

<a name="wiring"></a>

## Подключите светодиоды

Отключите USB-питание. Каждый вывод подключите через свой резистор к аноду (+)
светодиода. Все катоды (−) соедините с GND; к 5V светодиоды не подключайте.

Схема для ESP32-C3 SuperMini: используйте выводы со стороны GND, пропустив
GPIO2 — он участвует в выборе режима загрузки.
