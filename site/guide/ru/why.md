# Почему BroGlow

<a name="clawlight"></a>

## Спасибо ClawLight

BroGlow не появился бы без [ClawLight](https://github.com/clawlight/clawlight-cli).
Его идея — небольшая настольная лампа, показывающая, чем заняты ваши coding-агенты, —
лежит в основе BroGlow, а сам BroGlow начинался как форк его кода. Мы с уважением
относимся к оригинальному проекту и его авторам: ClawLight доказал, что идея работает,
и вдохновил нас развить её дальше. BroGlow — отдельное, независимо поддерживаемое
приложение; ниже на этой странице перечислено, что в нём добавлено.

У сессий настоящие названия, значки агента и хоста, группировка по проектам и открытие
нужного разговора одним нажатием; лампа работает по Bluetooth на macOS с настройкой,
именами и яркостью для каждой лампы; установка идёт через Homebrew с безопасными
обновлениями; печатный корпус получил сменного магнитного маскота и интерактивное
руководство по сборке.

<a name="sessions"></a>

## Сессии

| Что улучшилось | Что это даёт вам |
| --- | --- |
| **Открытие нужного разговора** | Нажмите на сессию, чтобы попасть в её чат Claude, задачу Codex или окно терминала. |
| **Настоящие названия сессий** | Сессии показывают собственные заголовки Claude и переименованные задачи Codex вместо «Session abc123». |
| **Агент и хост с первого взгляда** | В каждой строке видно, какой агент работает (Claude, Codex, opencode, Copilot) и где (приложение, терминал, IDE). |
| **Группировка по проектам** | Сессии собраны под заголовком своей рабочей директории; одноимённые папки различаются. |
| **Улучшенная обработка статусов** | Состояния «работает», «ждёт» и «нужен ответ» точнее следуют за действиями агента — и для Claude, и для Codex. |
| **Очистка приостановленных сессий** | Уберите лишнее одним нажатием: работающие сессии и запросы разрешений останутся видимыми. |

Подробнее: [Работа с сессиями](sessions.md).

<a name="lamp"></a>

## Лампа

| Что улучшилось | Что это даёт вам |
| --- | --- |
| **Беспроводное подключение** | Ставьте лампу где угодно в зоне Bluetooth — кабель данных к Mac не нужен. |
| **Подключили — и готово** | Новая лампа по USB настраивается на macOS сама; **Добавить лампу** остаётся для ручного повтора. |
| **Управление каждой лампой отдельно** | Назовите, забудьте или найдите одну лампу — остальные останутся подключёнными, у каждой свой статус. |
| **Предпросмотр яркости** | Выберите комфортную яркость для каждой лампы и оцените результат до сохранения. |
| **Поиск нужной лампы** | Включите трёхпроходное мигание выбранной лампы, чтобы убедиться, какой лампой вы управляете. |
| **Безопасная прошивка** | Один зафиксированный набор инструментов прошивает и бэкапит плату одинаково на любой машине. |

Подробнее: [Установка и подключение](installation.md#pairing).

<a name="install"></a>

## Установка и обновление

| Что улучшилось | Что это даёт вам |
| --- | --- |
| **Установка через Homebrew** | `brew install broglow/tap/broglow`, затем `broglow install`; обновления тем же путём. |
| **Обновления без поломок** | Настройки пишутся атомарно, неудачное обновление на macOS откатывается, симлинки dotfiles сохраняются, удаление убирает все хуки. |
| **Учёт расхода токенов** | Опциональный показ 5-часового и недельного лимита плана в процентах и токенов за сегодня — Claude и Codex вместе. |
| **Поповер на 120 fps** | Интерфейс в строке меню рисуется с полной частотой вашего дисплея: плавная прокрутка, настройки отзывчивы даже пока агенты работают. |

Подробнее: [Установка и подключение](installation.md).

## Сборка и документация

| Что улучшилось | Что это даёт вам |
| --- | --- |
| **Печать корпуса и смена маскота** | Маскот держится на магнитах: поставьте любого маскота и меняйте его когда угодно. |
| **Интерактивное руководство по сборке** | Вращайте и приближайте разнесённые детали, чтобы понять, как они соединяются. |

Подробнее: [Сборка лампы](index.md) и [Печать и сборка](printing.md).

Функции Bluetooth-ламп (беспроводное управление, автоматическая настройка, имена,
яркость отдельных ламп, **Identify**) и прямое открытие сессий настольных приложений
доступны только на macOS. Лампе по-прежнему нужно питание; устройство рассчитано на
самостоятельную сборку.
