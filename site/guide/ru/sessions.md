# Работа с сессиями

Сессии всех подключённых агентов попадают в один список — в поповере строки меню и в
терминальной панели — и управляют одной лампой.

<a name="open-session"></a>

## Вернуться к сессии

Нажмите на сессию в BroGlow (в TUI — **Enter**), чтобы вывести её на передний план:
окно или вкладку терминала, где она запущена, диалог в приложении Claude или задачу
приложения Codex по её ссылке (в том числе если приложение называется ChatGPT). Если
вывести хост не удалось, сессия Codex открывается по ссылке на задачу в приложении Codex.
На macOS строка T3 Code открывает нужный тред в соответствующем приложении T3 Code.

<a name="session-names"></a>

## Названия сессий

BroGlow показывает название, которое хранит сам агент: сохранённое название Claude Code
(автоматическое из приложения или заданное через `/rename`), название треда Codex,
название сессии opencode и название треда T3 Code. Пока названия нет, Claude, Codex и
opencode используют первые ~50 символов первого запроса (сессии Copilot — всегда);
сессия Claude Code без названия получает
короткое название, сгенерированное в конце первого хода. До первого запроса сессия отображается
как `Session <id>`. Новое или изменённое название появляется в течение пяти секунд,
пока список открыт; наведите указатель на название, чтобы увидеть его полностью.

Ссылки Markdown отображаются как читаемый текст: `[book](book)` становится `book`.
Меняется только отображение, а сохранённое у агента название остаётся прежним.

<a name="question-expiry"></a>

## Пропущенные вопросы

Ожидающие ответа вопросы T3 показываются как **Needs help**, включая асинхронные
вопросы, пока модель продолжает работу. Красный сохраняется, пока T3 не подтвердит
ответ или закрытие вопроса; завершение хода модели само по себе не закрывает вопрос
T3, на который ещё можно ответить. Для обычных вопросов Codex подтверждённое
завершение хода может закрыть вопрос без ответа.

Когда показанный вопрос закрывается без ответа, подключённая лампа выполняет три
цикла в одном направлении: **красный → жёлтый → зелёный → красный**. Начало — от
последнего успешно записанного цвета, между переходами проходит не менее **100 ms**.
Затем лампа продолжает движение через промежуточные цвета до текущего состояния
сессий. Девять видимых переходов занимают 900 ms; каждая подтверждённая фаза, включая
конечный цвет, удерживается не менее 100 ms. Для возврата могут понадобиться ещё
два перехода, а задержки записи — удлинить эффект. Если текущий цвет неизвестен,
начало — с красного. Красный общий статус не подавляет сканирование.

У соответствующего чата появляется спокойная строка **Question skipped · 2m ago**
под агентом и проектом. Текущий статус и время активности не меняются. Заметка
следует обычной видимости сессии: отдельного раздела истории нет, завершённый чат
не удерживается в списке. Ответы и ошибки создания вопроса не вызывают этот эффект.

Старые эффекты не повторяются после переподключения или перезапуска. Яркость,
включая нулевую, и Identify сохраняют обычный приоритет. Если одновременно поступили
перегрузка и пропущенный вопрос, сначала идут вспышки перегрузки, затем ожидающее
сканирование. Неизвестные или отсутствующие данные не снимают ожидающий ответа вопрос.

<a name="model-capacity"></a>

## Модель перегружена

Когда обычный Codex или локальная проекция T3 подтверждает завершение хода из-за
перегрузки модели, BroGlow показывает **Needs help** и **Model at capacity**.
Кнопка сессии открывает соответствующее приложение, чтобы выбрать другую модель
или повторить запрос. Общие ошибки провайдера, ограничения квоты и упоминания
перегрузки в тексте не вызывают анимацию перегрузки.

Подключённая лампа быстро мигает красным пять раз, примерно **150 ms включено /
150 ms выключено**, затем возвращается к текущему состоянию сессий — обычно красному,
пока нужна помощь. Каждый неудачный ход вызывает одну серию, в том числе поверх
красного. Новая попытка снимает предупреждение; **×** скрывает строку, не меняя чат.
Открытие списка, перезапуск BroGlow и переподключение лампы не повторяют эффект.

MCP связанных машин сейчас передаёт число ожидающих запросов без структурированных
кодов перегрузки и всех причин закрытия вопросов. Такие вопросы по-прежнему
включают красный; явно отменённые элементы вопросов вызывают заметку и сканирование.
Другие причины закрытия и перегрузка не определяются по тексту.

<a name="dismiss"></a>

## Убрать сессию из списка

Нажмите **×** рядом с сессией (в TUI — **x**), чтобы скрыть её из списка BroGlow и из
расчёта цвета лампы. Диалог в агенте сохранится, а сессия вернётся при новой
активности, например при вашем следующем запросе. T3 Code опрашивается без хуков;
одного переименования скрытого треда недостаточно, чтобы он появился снова. В поповере строки меню кнопка
**Clear paused** рядом с заголовком Paused убирает сразу все жёлтые сессии.
