# Работа с сессиями

Сессии всех подключённых агентов попадают в один список — в поповере строки меню и в
терминальной панели — и управляют одной лампой.

<a name="open-session"></a>

## Вернуться к сессии

Нажмите на сессию в BroGlow (в TUI — **Enter**), чтобы вывести её на передний план:
окно или вкладку терминала, где она запущена, диалог в приложении Claude или задачу
приложения Codex по её ссылке (в том числе если приложение называется ChatGPT). Если
вывести хост не удалось, сессия Codex открывается по ссылке на задачу в приложении Codex.

<a name="session-names"></a>

## Названия сессий

BroGlow показывает название, которое ведёт сам агент: сохранённое название Claude Code
(автоматическое из приложения или заданное через `/rename`), название треда Codex,
название сессии opencode. Пока его нет, сессия называется по первым ~50 символам
первого запроса (сессии Copilot — всегда); сессия Claude Code без названия получает
короткое сгенерированное в конце первого хода. До первого запроса сессия отображается
как `Session <id>`. Новое или изменённое название появляется в течение пяти секунд,
пока список открыт; наведите указатель на название, чтобы увидеть его полностью.

<a name="question-expiry"></a>

## Истёкшие вопросы Codex

Codex может задать необязательный вопрос и продолжить работу. Если ход завершился
без ответа, BroGlow снимает **Needs help**, когда Codex подтвердит завершение.
Подключённая лампа мигает красным три раза, примерно по 500 ms на вспышку, затем
возвращается к текущему цвету сессий. Список всё это время показывает реальное состояние.

Ответ снимает уведомление без вспышек. Если другая сессия ждёт помощи, лампа остаётся
постоянно красной. Старые эффекты не повторяются после переподключения или перезапуска;
яркость, включая нулевую, и идентификация лампы сохраняют обычное поведение.

Если завершение не удалось подтвердить или вопрос записала старая версия BroGlow
без данных отслеживания, уведомление остаётся. Нажмите **×**, чтобы убрать эту строку;
это не отвечает на вопрос и не удаляет чат.

<a name="model-capacity"></a>

## Модель Codex перегружена

Когда Codex подтверждает, что ход завершился ошибкой из-за перегрузки выбранной
модели, BroGlow показывает **Needs help** и **Model at capacity** в строке сессии.
Нажмите **Open Codex**, затем выберите другую модель или повторите запрос в Codex.

Подключённая лампа быстро мигает красным пять раз, примерно **150 ms включено /
150 ms выключено**, затем остаётся красной, пока сессии нужна помощь. Значок строки
меню всё это время красный. Каждый неудачный ход вызывает одну серию вспышек,
даже если лампа уже была красной. Открытие списка, перезапуск BroGlow и
переподключение лампы не повторяют эффект.

Новая попытка снимает предупреждение. **×** скрывает его, не меняя чат.
Яркость и Identify сохраняют обычный приоритет; подавленная или отменённая серия
не воспроизводится позже. Задержки записи Bluetooth могут удлинить вспышки.

<a name="dismiss"></a>

## Убрать сессию из списка

Нажмите **×** рядом с сессией (в TUI — **x**), чтобы скрыть её из списка BroGlow и из
расчёта цвета лампы. Диалог в агенте сохранится, а сессия вернётся при следующем
событии хука, например при вашем следующем запросе. В поповере строки меню кнопка
**Clear paused** рядом с заголовком Paused убирает сразу все жёлтые сессии.
