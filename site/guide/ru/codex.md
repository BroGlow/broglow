# Подключите Codex { #codex-setup }

Установка ClawLight добавляет hooks, но для их запуска Codex нужно ваше разрешение.

1. Откройте Codex CLI (0.144+) в Терминале. Для задач в приложении используйте того же пользователя и CODEX_HOME: подойдёт встроенный CLI приложения или установленная команда codex.
2. Введите /hooks. Проверьте и разрешите шесть записей ClawLight с командой clawlight codex-hook. Остальные hooks оставьте без изменений. После изменения обработчиков разрешение может потребоваться снова.
3. Отправьте запрос в новой локальной задаче Codex — в CLI или приложении. В списке сессий ClawLight проверьте смену статуса этой задачи: Working во время работы, затем Idle/Paused после ответа. Needs you/Needs help появляется при запросе разрешения. На цвет лампы также влияют другие живые сессии.

Старым чатам в боковой панели нужен новый запрос. Если сессия не появилась, завершите активную
работу, перезапустите Codex и попробуйте снова. Одного статуса Bluetooth «connected»
недостаточно: передача событий из приложения не подтверждена, пока проверку не пройдёт задача
именно в приложении.

Эта настройка рассчитана на задачи, выполняемые на этом Mac. Обычные чаты ChatGPT и облачные
или удалённые задачи не передают события локальной службе ClawLight на Mac.

Нажмите на локальную сессию Codex, чтобы вернуться к ней. На macOS задача из
приложения открывается по своей ссылке в Codex, в том числе в приложении ChatGPT.
Для CLI открывается сохранённое окно терминала; если его не удалось найти,
ClawLight пробует ссылку на задачу в установленном приложении Codex.
