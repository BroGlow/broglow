# Подключите Codex

Установка BroGlow добавляет hooks, но для их запуска Codex нужно ваше разрешение.

1. Откройте Codex CLI (0.144+) в Терминале. Для задач в приложении используйте того же пользователя и CODEX_HOME: подойдёт встроенный CLI приложения или установленная команда codex.
2. Введите /hooks. Проверьте и разрешите шесть записей BroGlow с командой broglow codex-hook. Остальные hooks оставьте без изменений. После изменения обработчиков разрешение может потребоваться снова.
3. Отправьте запрос в новой локальной задаче Codex — в CLI или приложении. В списке сессий BroGlow проверьте смену статуса этой задачи: Working во время работы, затем Idle/Paused после ответа. Needs you/Needs help появляется при запросе разрешения. На цвет лампы также влияют другие живые сессии.

Старым чатам в боковой панели нужен новый запрос. Если сессия не появилась, завершите активную
работу, перезапустите Codex и попробуйте снова. Одного статуса Bluetooth «connected»
недостаточно: передача событий из приложения не подтверждена, пока проверку не пройдёт задача
именно в приложении.

Эта настройка рассчитана на задачи, выполняемые на этом Mac. Обычные чаты ChatGPT и облачные
или удалённые задачи не передают события локальной службе BroGlow на Mac.

Нажмите на локальную сессию Codex, чтобы вернуться к ней. На macOS задача из
приложения открывается по своей ссылке в Codex, в том числе в приложении ChatGPT.
Для CLI открывается сохранённое окно терминала; если его не удалось найти,
BroGlow пробует ссылку на задачу в установленном приложении Codex.

Пока Codex не сохранил название, безымянная сессия получает начало первого
отправленного запроса: пробельные символы нормализуются, длина ограничена
50 символами, включая `...`. Это работает и для временных side-chats без
транскрипта. Последующие запросы сохраняют название; до первого непустого
запроса вместо него может отображаться ID сессии.

Название сессии обновляется в течение пяти секунд после того, как Codex сохранил
созданное или изменённое название. Новый запрос не нужен; статус и время последней
активности сессии не меняются.
Наведите указатель на название сессии, чтобы увидеть полное сохранённое название.

Нажмите **×** рядом с сессией в BroGlow, чтобы убрать её из списка и расчёта цвета
лампы. Диалог Codex сохранится и автоматически появится в BroGlow при новом
запросе или другой активности. Простое открытие диалога не возвращает его в список.
**Clear paused** рядом с заголовком Paused делает то же самое сразу для всех жёлтых
сессий. Зелёные работающие и красные сессии, которым нужна помощь, остаются в списке.
