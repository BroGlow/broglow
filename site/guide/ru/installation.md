# Установка и подключение

<a name="installation"></a>

## Установите ClawLight и прошивку

Используйте полный пакет этого проекта: приложение для Mac, прошивку ESP32-C3
и руководство. Выберите сборку для процессора своего Mac. Apple Silicon проверена
на устройстве; для Intel ещё нужны проверки установки и Bluetooth.

<a name="agent-setup"></a>

## Настройте с помощью coding-агента

Распакуйте пакет или архив исходников, откройте его в coding-агенте и вставьте
запрос ниже. Сохраните рядом файл контрольной суммы пакета. Для ручной настройки
следуйте [инструкции установки](hardware.md#install-or-update-the-mac-service).

```text
Настрой ClawLight по разделу «Инструкция для агента» в docs/hardware-setup.ru.md.
Выбери установку из пакета или исходников, проверь контрольные суммы пакета и сохрани
копию настроек в .recovery/. Сохрани hooks, имена ламп, яркость и сопряжения; оставь одну службу.
Перед аппаратными командами проверь, что плата — ESP32-C3 SuperMini; прошивай только при необходимости.
Используй Lamps → Add lamp с одной лампой по USB. Запросы macOS и Codex /hooks подтвержу я;
для Codex используй тот же CODEX_HOME, что у приложения.
Проверь запуск clawlight в новом терминале вне проекта, соединение фоновой службы с моей
лампой и смену Working на Idle/Paused у реальной локальной задачи агента.
Если я использую приложение Codex, проверь задачу в нём. Укажи оставшиеся физические проверки.
```

## Запускайте ClawLight из любой папки

ClawLight устанавливается в `~/.cargo/bin/clawlight`; готовый пакет не требует Cargo.
В новом терминале вне проекта проверьте:

--8<-- "docs/hardware-setup.ru.md:path-check"

Если первый результат — не `~/.cargo/bin/clawlight`, добавьте эту строку **один раз**
в `~/.zshrc` (стандартная оболочка macOS), сохранив остальные настройки:

--8<-- "docs/hardware-setup.ru.md:path-setup"

Откройте новый терминал и повторите проверку. Не дублируйте путь, если Rust уже настроил
`~/.cargo/env`; для другой оболочки используйте её файл запуска. `clawlight install`
не настраивает `PATH`. В скриптах можно вызывать `"$HOME/.cargo/bin/clawlight"` напрямую;
служба при входе в систему уже использует абсолютный путь.

<a name="pairing"></a>

## Подключите один раз и поставьте на стол

Подключите одну прошитую лампу кабелем USB с передачей данных. Откройте статус лампы
в окне из строки меню, затем **Lamps → Add lamp**. Разрешите Bluetooth и подтвердите
сопряжение macOS. Добавляйте лампы по одной; остальные останутся в списке.

Альтернатива через Терминал:

```sh
clawlight ble pair
clawlight ble status
```

Дождитесь **Connected** в строке нужной лампы: «Lamp added» означает лишь сохранение.
Connected подтверждает передачу статуса, но не работу светодиодов. Оставьте питание
от Mac или USB-блока; ClawLight повторяет подключение, пока служба, управление лампой
и Bluetooth включены, а лампа находится рядом.

<a name="controls"></a>

## Настройте яркость и список ламп

Откройте **Lamps** и раскройте строку лампы:

- **Имя:** до 40 символов, сохраняется на этом Mac; пустое возвращает автоматическую подпись.
- **Identify:** включает три светодиода этой подключённой лампы на полную яркость на две
  секунды, затем возвращает статус сессии без изменения настроек.
- **Light brightness:** 0–100% для этой лампы. **All lamps** заменяет индивидуальную яркость
  всех сохранённых ламп. Предпросмотр заканчивается через две секунды после последнего изменения.
- **Forget lamp:** удаляет лампу из списка на Mac; остальные лампы и Bluetooth-сопряжения остаются.

При 0% светодиоды выключены, Bluetooth подключён, а **Identify** по-прежнему работает.
Изменения яркости без соединения применятся при подключении, не включая управление лампой.

Терминальный Dashboard необязателен: его кнопку можно показать через
**Settings → Appearance → Show Dashboard button**.

Прошивка, восстановление и актуальные [результаты проверок](hardware.md#repeatable-checks-and-results)
описаны в [техническом руководстве](hardware.md).
