# Установка и подключение { #install }

## Установите ClawLight и прошивку { #installation }

Скачайте BLE-пакет для Mac с Apple Silicon (M1 и новее). Внутри приложение и прошивка C3. Для
Intel нужна отдельная сборка; в оригинальном Homebrew-пакете этой BLE-версии нет.

## Настройте с помощью coding-агента { #agent-setup }

Распакуйте пакет или архив исходников, откройте эту папку в Codex или другом coding-агенте и
вставьте запрос ниже. Для готового пакета сохраните рядом файл контрольной суммы. Подробные
шаги для ручной установки находятся в `docs/hardware-setup.md` внутри папки.

```text
Помоги настроить ClawLight по docs/hardware-setup.md. Если это готовый пакет, проверь
контрольные суммы; если исходники — следуй инструкции сборки. Сохрани резервную копию настроек
и одну службу в строке меню. Определи мою плату перед аппаратными командами.
Прошивка проекта рассчитана на ESP32-C3; другой SuperMini с
Bluetooth LE нужны подходящие прошивка и выводы. Если пакет не поддерживает мою плату, объясни,
что потребуется, до прошивки. Прошивай только при необходимости и сохрани сопряжения. Скажи,
когда подключить кабель или подтвердить диалог macOS, затем проверь соединение фоновой службы с
лампой. Для Codex помоги мне проверить и разрешить шесть hooks ClawLight через /hooks в CLI с
тем же CODEX_HOME, что у приложения; разрешение дам я. Проверь смену Working на Idle/Paused в
ClawLight для реальной локальной задачи в CLI или приложении: одного статуса BLE недостаточно.
Для работы через приложение проведи проверку именно в нём.
```

## Подключите один раз и поставьте на стол { #pairing }

Соедините прошитую лампу с Mac кабелем USB с передачей данных. Выполните команды в Терминале,
разрешите ClawLight доступ к Bluetooth и подтвердите сопряжение в окне macOS.

```sh
~/.cargo/bin/clawlight ble pair
~/.cargo/bin/clawlight ble status
```

Проверьте «connected» у нужной лампы: фоновой службе удалось передать ей статус. Это ещё не
проверка самих светодиодов. Оставьте питание от Mac или подключите отдельный USB-блок.
ClawLight автоматически повторяет подключение, пока служба работает, управление лампой и
Bluetooth включены, а лампа рядом и получает питание.
