# Установка и подключение

<a name="homebrew"></a>

## Установка через Homebrew

```bash
brew install broglow/tap/broglow
broglow install
```

`broglow install` — обязательный шаг: он регистрирует хуки BroGlow в ваших
coding-агентах (Claude Code — всегда; Codex, opencode и GitHub Copilot CLI — если
они установлены), устанавливает приложение в строке меню и включает его запуск при
входе. Нет Homebrew, Windows или Linux? См. [Другие способы установки](alternatives.md).

<a name="agent-setup"></a>

## Настройте с помощью агента

Откройте папку в агенте (Codex, Claude Code и т. п.) и вставьте запрос ниже. Если вы
используете [пакет для Mac](alternatives.md#mac-package), сначала распакуйте его,
оставьте архив и его файл `.sha256` рядом и откройте эту папку.
Для ручной настройки следуйте [инструкции установки](hardware.md#install-or-update-the-mac-service).

```text
Настрой BroGlow на этом Mac по «Инструкции для агента»:
{{ repo_url }}/blob/HEAD/site/guide/ru/hardware.md#agent-runbook
Используй пакет или исходники BroGlow в этой папке. Если их нет, скачай пакет для
этого Mac из {{ repo_url }}/releases и проверь его .sha256.
Перед изменениями сохрани копию моих настроек. Сохрани посторонние хуки и их порядок,
имена ламп, яркость и Bluetooth-сопряжения; служба в строке меню должна быть одна.
Лампа (если подключена): сначала убедись, что плата — ESP32-C3 SuperMini. Прошивай её,
только если на ней нет рабочей прошивки BroGlow, и только с моего согласия. Затем
настрой её по USB (повтор: broglow ble pair).
Запросы macOS на Bluetooth и сопряжение, а также доверие хукам в Codex (/hooks)
оставь мне; для Codex используй тот же CODEX_HOME, что у приложения Codex.
Проверь: broglow запускается в новом терминале вне этой папки; broglow ble status
показывает мою лампу подключённой; реальная локальная задача агента переходит из
Working в Paused (если я пользуюсь приложением Codex, проверь задачу в нём).
Затем попроси меня нажать Identify у лампы и подтвердить проход красный → жёлтый → зелёный.
Если прохода нет, прошивка может быть старше Identify: сообщи об этом, не прошивай.
В отчёте перечисли: что установлено или изменено, результат каждой проверки и что
осталось подтвердить мне.
```

<a name="path"></a>

## Откройте BroGlow и проверьте команду

Чтобы открыть приложение на Mac, нажмите **⌘ Space**, найдите **BroGlow** и нажмите
Return. Значок со светофором открывает управление сессиями. Также можно открыть
`~/Applications/BroGlow.app` в Finder или выполнить `open "$HOME/Applications/BroGlow.app"`.
Приложение запускается при входе в систему. Команда `broglow` без аргументов открывает
терминальную панель; при первом запуске на ненастроенном Mac она также регистрирует хуки и автозапуск.

При установке через Homebrew команда `broglow` лежит в `$(brew --prefix)/bin/broglow`,
который уже есть в PATH. Готовый пакет и сборка из исходников кладут её в
`~/.cargo/bin/broglow` (для готового пакета Cargo не нужен). В новом терминале вне
проекта проверьте:

<a name="pairing"></a>

## Подключите один раз и поставьте на стол

Подключите одну прошитую лампу кабелем USB с передачей данных. На macOS BroGlow
начинает настройку автоматически в течение пяти секунд. Разрешите Bluetooth и подтвердите
запрос сопряжения macOS, если он появится. Чтобы повторить, нажмите кнопку **Lamp**
внизу меню (при нескольких лампах она называется **Lamps**) и выберите **Add lamp**.
Добавляйте лампы по одной; остальные останутся в списке.

Альтернатива через Терминал:

```sh
broglow ble pair
broglow ble status
```

Дождитесь **Connected** в строке нужной лампы: **Lamp added** означает лишь, что лампа
сохранена. Connected подтверждает передачу статуса, но не работу светодиодов. Затем
питайте лампу от Mac или USB-блока. BroGlow сам переподключается, когда лампа рядом,
если приложение запущено, а управление лампой и Bluetooth включены.
Для нескольких плат или при ошибке настройки см. раздел [«Настройка с помощью USB»](hardware.md#usb-assisted-setup).

<a name="controls"></a>

## Настройте яркость и список ламп

Нажмите кнопку **Lamp** внизу меню и раскройте строку лампы:

- **Name:** до 40 символов, сохраняется на этом Mac; пустое поле возвращает автоматическую подпись.
- **Identify:** трижды проходит по светодиодам подключённой лампы красный → жёлтый → зелёный,
  включая по одному на 100%, по 100 мс на светодиод (всего 0,9 секунды), затем возвращает
  последний статус и сохранённую яркость без изменения настроек.
- **Light brightness:** 0–100% для этой лампы. **All lamps** заменяет индивидуальную яркость
  всех сохранённых ламп. Предпросмотр заканчивается через две секунды после последнего изменения.
- **Forget lamp:** удаляет лампу вместе с её именем и яркостью из списка на этом Mac; остальные
  лампы и Bluetooth-сопряжения остаются. Если удалить последнюю лампу, управление лампой выключится.

При 0% управляемые светодиоды погашены (красный индикатор питания платы горит), Bluetooth
остаётся подключённым, а **Identify** работает на подключённой лампе.
Яркость можно менять, когда лампа не подключена: значение применится при подключении,
а управление лампой это не включает.
Для Identify нужна актуальная прошивка BroGlow; старая прошивка проход не показывает.
Обновление приложения не прошивает плату; см. [шаги обновления прошивки](hardware.md#flash-and-recover-usb-upload).

Терминальная панель необязательна: её кнопку можно показать через
**Settings → Appearance → Show Dashboard button** или командой `broglow dashboard-button show`.

Прошивка, восстановление и актуальные [результаты проверок](hardware.md#repeatable-checks-and-results)
описаны в [техническом руководстве](hardware.md).
