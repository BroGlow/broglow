# Установка и подключение

<a name="homebrew"></a>

## Установка через Homebrew

```bash
brew install broglow/tap/broglow
broglow install
```

`broglow install` — обязательный шаг: он регистрирует хуки BroGlow в ваших
coding-агентах (Claude Code — всегда; Codex, opencode и GitHub Copilot CLI — если
они установлены), устанавливает приложение в строке меню и включает его запуск при
входе. Нет Homebrew, Windows или Linux? См. [Другие способы установки](alternatives.md).

<a name="open"></a>

## Откройте BroGlow

Чтобы открыть приложение на Mac, нажмите **⌘ Space**, найдите **BroGlow** и нажмите
Return. Значок со светофором в строке меню открывает управление сессиями; приложение
запускается при входе в систему. В Terminal команда `broglow` открывает панель.

<a name="colors"></a>

## Что значат цвета

Лампа показывает сводный статус всех локальных сессий: **зелёный** — агент
работает, **жёлтый** — сессия закончила ход и ждёт вас, **красный** — агент задал
вопрос или ждёт разрешения. Теми же цветами отмечены сессии в окне приложения;
при разных статусах выбор между зелёным и жёлтым задаёт **Settings → Mixed sessions**.

<a name="pairing"></a>

## Подключите один раз и поставьте на стол

Подключите одну прошитую лампу кабелем USB с передачей данных. На macOS BroGlow
начинает настройку автоматически в течение пяти секунд. Разрешите Bluetooth и подтвердите
запрос сопряжения macOS, если он появится. Чтобы повторить, нажмите кнопку **Lamp**
внизу меню (при нескольких лампах она называется **Lamps**) и выберите **Add lamp**.
Добавляйте лампы по одной; остальные останутся в списке.

Альтернатива через Терминал:

```sh
broglow ble pair
broglow ble status
```

Дождитесь **Connected** в строке нужной лампы: **Lamp added** означает лишь, что лампа
сохранена. Connected подтверждает передачу статуса, но не работу светодиодов. Затем
питайте лампу от Mac или USB-блока. BroGlow сам переподключается, когда лампа рядом,
если приложение запущено, а управление лампой и Bluetooth включены.
Для нескольких плат или при ошибке настройки см. раздел [«Настройка с помощью USB»](hardware.md#usb-assisted-setup).

<a name="controls"></a>

## Настройте яркость и список ламп

Нажмите кнопку **Lamp** внизу меню и раскройте строку лампы:

- **Name:** до 40 символов, сохраняется на этом Mac; пустое поле возвращает автоматическую подпись.
- **Identify:** быстро зажигает красный, жёлтый и зелёный светодиоды подключённой лампы
  по одному, несколько раз подряд, затем возвращает текущий статус без изменения настроек.
- **Light brightness:** 0–100% для этой лампы. **All lamps** заменяет индивидуальную яркость
  всех сохранённых ламп. Предпросмотр заканчивается через две секунды после последнего изменения.
- **Forget lamp:** удаляет лампу вместе с её именем и яркостью из списка на этом Mac; остальные
  лампы и Bluetooth-сопряжения остаются. Если удалить последнюю лампу, управление лампой выключится.

На macOS забытая лампа добавляется снова, если отключить её USB-кабель минимум на
пять секунд и подключить снова. **Settings → Lamps → Automatically add forgotten lamps
over USB** включена по умолчанию; выключите её, если подключаете лампы только для
питания. **Add lamp** всегда работает с USB-кабелем передачи данных. Forget оставляет
лампу отключённой, пока кабель подключён; перезапуск приложения не добавляет её снова.
Сохранённые выключенные лампы остаются выключенными.

При 0% управляемые светодиоды погашены (красный индикатор питания платы горит), Bluetooth
остаётся подключённым, а **Identify** работает на подключённой лампе.
Яркость можно менять, когда лампа не подключена: значение применится при подключении.
Если управление лампой выключено, изменение яркости его не включит.
Для Identify нужна актуальная прошивка BroGlow; старая прошивка проход не показывает.
Обновление приложения не прошивает плату; см. [шаги обновления прошивки](hardware.md#flash-and-recover-usb-upload).

Терминальная панель необязательна: её кнопку можно показать через
**Settings → Appearance → Show Dashboard button** или командой `broglow dashboard-button show`.

Прошивка и восстановление описаны в [техническом руководстве](hardware.md).
