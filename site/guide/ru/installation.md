# Установка и подключение { #install }

## Установите ClawLight и прошивку { #installation }

Скачайте BLE-пакет для Mac с Apple Silicon (M1 и новее). Внутри приложение и прошивка C3. Для
Intel нужна отдельная сборка; в оригинальном Homebrew-пакете этой BLE-версии нет.

## Настройте с помощью coding-агента { #agent-setup }

Распакуйте пакет или архив исходников, откройте эту папку в Codex или другом coding-агенте и
вставьте запрос ниже. Для готового пакета сохраните рядом файл контрольной суммы. Подробные
шаги для ручной установки находятся в `docs/hardware-setup.md` внутри папки.

```text
Помоги настроить ClawLight по docs/hardware-setup.md. Если это готовый пакет, проверь
контрольные суммы; если исходники — следуй инструкции сборки. Сохрани резервную копию настроек
и одну службу в строке меню. Проверь в новом терминале вне проекта, что команда clawlight
запускает установленную BLE-версию; настрой PATH только при необходимости, сохрани настройки
оболочки и не дублируй записи. Определи мою плату перед аппаратными командами.
Прошивка проекта рассчитана на ESP32-C3; другой SuperMini с
Bluetooth LE нужны подходящие прошивка и выводы. Если пакет не поддерживает мою плату, объясни,
что потребуется, до прошивки. Прошивай только при необходимости и сохрани сопряжения. Скажи,
когда подключить кабель или подтвердить диалог macOS, затем проверь соединение фоновой службы с
лампой. Для Codex помоги мне проверить и разрешить шесть hooks ClawLight через /hooks в CLI с
тем же CODEX_HOME, что у приложения; разрешение дам я. Проверь смену Working на Idle/Paused в
ClawLight для реальной локальной задачи в CLI или приложении: одного статуса BLE недостаточно.
Для работы через приложение проведи проверку именно в нём.
```

## Запускайте ClawLight из любой папки { #path }

ClawLight устанавливается один раз для вашей учётной записи Mac в `~/.cargo/bin/clawlight`.
Открывать папку проекта для запуска не нужно. Готовый пакет не требует Cargo.
В новом окне Терминала проверьте:

--8<-- "docs/hardware-setup.md:path-check"

Первый результат должен указывать на ваш `~/.cargo/bin/clawlight`. Если так и есть, ничего
менять не нужно. Если команда не найдена или первой запускается старая копия из Homebrew,
добавьте эту строку **один раз** в `~/.zshrc` для стандартной оболочки macOS zsh, сохранив
остальные настройки:

--8<-- "docs/hardware-setup.md:path-setup"

Откройте новое окно Терминала и повторите проверку. Сам по себе `export` в текущем окне не
настраивает будущие окна. Rust уже мог настроить путь через `~/.cargo/env`; не дублируйте
записи. Для другой оболочки используйте её файл настроек запуска.

`clawlight install` настраивает hooks и службу в строке меню, но не `PATH`. Скрипты и
подпроцессы агентов могут не читать настройки оболочки: используйте в них
`"$HOME/.cargo/bin/clawlight"` или настройте их `PATH`. Служба при входе в систему уже
использует абсолютный путь и не зависит от `PATH` вашего терминала.

## Подключите один раз и поставьте на стол { #pairing }

Соедините прошитую лампу с Mac кабелем USB с передачей данных. Выполните команды в Терминале,
разрешите ClawLight доступ к Bluetooth и подтвердите сопряжение в окне macOS.

```sh
clawlight ble pair
clawlight ble status
```

Проверьте «connected» у нужной лампы: фоновой службе удалось передать ей статус. Это ещё не
проверка самих светодиодов. Оставьте питание от Mac или подключите отдельный USB-блок.
ClawLight автоматически повторяет подключение, пока служба работает, управление лампой и
Bluetooth включены, а лампа рядом и получает питание.

## Настройте яркость и список ламп { #controls }

Нажмите статус лампы внизу окна из строки меню, чтобы открыть **Lamps**.
Ползунок **Light brightness** задаёт 0–100%: подключённые Bluetooth-лампы показывают
яркость всеми тремя светодиодами и возвращаются к статусу сессий через две секунды
после последнего предпросмотра. При 0% управляемые светодиоды выключены, а Bluetooth остаётся подключённым.

Раскройте строку лампы, чтобы увидеть сведения о подключении или **Forget lamp**.
Терминальный Dashboard необязателен: его кнопку можно показать через
**Settings → Appearance → Show Dashboard button**.

Прошивка, восстановление и актуальные [результаты проверок](hardware.md#repeatable-checks-and-results)
описаны в [техническом руководстве (EN)](hardware.md).
