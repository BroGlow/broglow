A few little things.

Do I need the physical lamp?+

No. BroGlow works as a menu-bar or tray app and a terminal dashboard. The lamp is optional.

You can also 3D-print your own lamp. Get the models here:
Printables ↗ · MakerWorld ↗

Which agents does it work with?+

Claude Code, Codex (0.144 or newer), opencode, and GitHub Copilot CLI. BroGlow monitors local sessions; cloud tasks and ordinary web chats are outside its scope.

What if several agents need different things?+

A session needing input always makes the signal red. If working and paused sessions coexist, yellow wins by default; you can choose to prioritize active work in Settings.
