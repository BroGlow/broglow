# Демо главной страницы BroGlow

Здесь находится прототип главной страницы в палитре Ember; действующая страница
в `site/` не изменена. Команды ниже выполняются из корня репозитория. Достаточно
Node.js и Python 3; устанавливать зависимости npm не нужно.

<a name="preview"></a>
## Предпросмотр

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Откройте <http://127.0.0.1:8080/demos/homepage/>. Сервер должен обслуживать корень
репозитория: исходная страница загружает общие ресурсы приложения из `assets/`,
а ресурсы продукта — из `site/`. Открытие `index.html` через `file://` не работает.

<a name="build-and-check"></a>
## Сборка и проверки

```sh
node --test demos/homepage/*.test.cjs
node --test tests/js/lamp-status.test.mjs tests/js/popover-library.test.mjs
node demos/homepage/build.cjs
```

Результат по умолчанию — игнорируемый каталог `dist/homepage-demo/`. При работающем
сервере откройте <http://127.0.0.1:8080/dist/homepage-demo/>. Этот самостоятельный
каталог содержит общий интерфейс, значки, фотографии, GLB и закреплённые версии
браузерных библиотек; его можно раздавать без репозитория. После изменения исходников
повторите сборку. Сборщик сохраняет неизвестные файлы и отказывается писать
в посторонний непустой каталог.

<a name="review-scope"></a>
## Что проверять

Попробуйте EN/RU, System/Light/Dark, Working/Paused/Needs you и **Settings → Track usage**.
Демо использует настоящий интерфейс всплывающего окна с вымышленными сессиями
и имитацией нативного хоста. Настройки и удаление сессий сохраняются только в памяти;
демо не читает реальные сессии, не устанавливает программы и не управляет устройством.
Подробности — в [описании общего интерфейса](SHARED-UI.ru.md).

Обычная прокрутка страницы управляет 3D-моделью лампы; доступны ручной выбор состояния
и яркости, режим уменьшенного движения и запасной показ фото. Фотографии сохраняют
пропорции 7:5. Для AR нужен совместимый браузер телефона и обычно HTTPS; локальный
предпросмотр показывает подсказку для открытия на телефоне. Социальные роботы получают
статические метаданные на английском, браузер поддерживает EN/RU. AR на физическом
телефоне и обработку превью социальными платформами нужно проверять отдельно.

[Стенд размеров окна](viewport-check.html) помогает проверить узкие и широкие экраны.
[Сравнение впечатлений](comparison.html) содержит таблицу старой/новой страницы
и результаты трёх независимых ревью Lazarus. Тесты проверяют границы общего интерфейса,
настройки, учёт использования, терминал и переключение окон, локализацию, ресурсы,
3D/AR и социальные метатеги. Установленные службы, установщики и физическое
устройство в эти проверки не входят.
